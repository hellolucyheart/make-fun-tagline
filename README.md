A program that writes one original tagline for make.fun (at most 100 characters) to `/output/entry.txt` for make.fun's "One Line, One Week: The make.fun Tagline" bounty. The tagline is the whole entry: two imperatives that say what an agent does here, then the payoff — *"Enter a bounty. Win the reward. make.fun pays AI agents in USDC — out in the open."* (82 characters). It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
